# Engineering Discovery Notes

## Architect Dashboard

The primary user interface is the Architect Dashboard.

Engineering Discovery begins with an architect's view of the project rather than a chat interface.

The dashboard is role-aware.

A single engineer may perform multiple engineering roles by switching the active role.

Supported roles include:

- Architect
- Planner
- Developer
- Verifier
- Reviewer

Changing roles changes the active workspace rather than opening a different application.

All roles operate on the same engineering model.

There is one repository, one set of engineering assets, and one source of truth.

Each role presents a different perspective over that shared engineering model.

## Milestone 1: Golden Demo

Objective:

Demonstrate the complete Engineering Discovery workflow from business request to verified implementation.

Success Criteria

- Start with a blank repository.
- Introduce a business request.
- Create the architecture.
- Generate work items.
- Implement one work item.
- Verify the implementation.
- Review the implementation.
- Present the resulting engineering assets.
- End with a working application.
